## Контракт
- Вход:
  - `issue_key` (обязательно)
  - `branch` (опционально)
- Выход:
  - обновленный `agent_meta`
  - следующий skill: `yt-task-work`

# State machine
- Требуется оценка -> Оценка задачи -> Взять в работу -> В работе -> Готово к ревью -> Ревью -> Подтвержден

# План работы:
1. Проверяем, что задача в статусе "Требуется оценка". Иначе — завершаем выполнение.

2. Переводим задачу в статус "Оценка задачи".

3. Изучаем описание задачи.

4. Формируем:
  - план работ
  - acceptance criteria
  - риски
  - зависимости
  - оценку
  - тип задачи (BackEnd/FrontEnd)
  - требуемый грейд (Senior/Middle/Junior)

5. Создаем или обновляем блок agent_meta в описании задачи.

6. Переводим задачу в статус "Взять в работу".

7. Вызываем yt-task-work
