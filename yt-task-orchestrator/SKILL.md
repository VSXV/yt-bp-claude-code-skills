---
name: yt-task-orchestrator
description: Центральный управляющий skill. Анализирует статус задачи в Яндекс Трекере и вызывает соответствующий этап пайплайна. Единственная точка входа в процесс разработки.
---

# План работы:

1. Получаем задачу из Яндекс Трекера по ключу.

2. Извлекаем:
  - текущий статус задачи
  - agent_meta (если есть)

3. Если agent_meta отсутствует:
  - считаем задачу новой
  - вызываем yt-task-plan
  - завершаем выполнение

4. Проверяем наличие agent_meta.last_error:
  - если есть и attempts превышает лимит (например 3):
      - фиксируем причину
      - завершаем выполнение

5. В зависимости от статуса задачи:

  - "Требуется оценка":
      → вызываем yt-task-plan

  - "Оценка задачи":
      → вызываем yt-task-plan

  - "Взять в работу":
      → вызываем yt-task-work

  - "В работе":
      → вызываем yt-task-work

  - "Готово к ревью":
      → вызываем yt-task-review

  - "Ревью":
      → вызываем yt-task-review

  - "Подтвержден":
      → вызываем yt-task-deploy

  - "Деплой":
      → вызываем yt-task-deploy

  - "Можно тестировать":
      → вызываем yt-task-test

  - "Тестируется":
      → вызываем yt-task-test

  - "Готово к релизу":
      → вызываем yt-task-mr

  - "Завершено":
      → ничего не делаем

  - любой другой статус:
      - фиксируем в agent_meta.last_error:
          stage: orchestrator
          message: "Неизвестный статус"
      - завершаем выполнение

6. После выполнения любого skill:
  - обновляем agent_meta.status_history (добавляем текущий статус)

7. Завершаем выполнение
